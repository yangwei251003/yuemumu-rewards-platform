## 对旧测试的必要维护

最新V4将钱包放在“我的”页的展开区域，导航采用每页独立命令锁。旧测试还在寻找旧首页钱包/CTA并要求全局禁止切页。本轮改为通过当前真实入口访问，保持API余额对照、会话清理、无越权写入和错误恢复断言；导航测试额外验证旧页钱包读取挂起/取消时，新页仍可独立读取，旧结果不能替换当前页。

V4 API验收文件原来写死一个本机B分支端口。本轮改为验证B或integration隔离schema、loopback、有效且独立的配置端口，与工程本来的隔离目标一致；业务断言未删除，最终159测试没有跳过项。

Windows MySQL在含中文的审计路径启动时曾报datadir不存在；对相同新审计目录采用临时ASCII路径别名后成功。本轮未接入、导入或修改任何原数据库，最终仅保留公开源码所需资料。普通安装使用setup生成的私有本机数据目录，必要时用环境参数指定新ASCII目录。
