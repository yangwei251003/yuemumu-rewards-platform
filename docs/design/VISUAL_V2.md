# 两端视觉与交互升级

基线：`integration/g2` / `645a8b78cdbc49cd444aa3271a53ed020166c30c`。接口合同保持 0.14.0，SHA256 `72d571f3f5c7af3b21257b3fde15b370648e4900fd11a798d2006fb25329ae29`。

## 场景与设计决定

学生在明亮的课间走廊单手查看活动和成长记录；教员在电脑处理审核，领取人员在前台用手机核销。沿用蓝白与少量橙色，学生突出当前可执行入口，后台突出任务分类和阅读效率。没有加入新计分规则、接口字段、等级算法或替代后端。

- 学生首页：AI 无人机概念图、真实木能量与成长里程、可展开钱包状态、四个常用入口、学习与项目探索、最近账本。两项 pending 合计仅用作“待处理”摘要，不计入可用积分。
- 奖励：横向分类、搜索清空、按当前木能量/模拟余量筛选、升降序排序；返回详情前的搜索状态保留。达到木能量要求不表示已经获得资格或库存预占，原确认和服务器校验照常执行。
- 我的：12个既有功能分为“我的记录”“成长与参与”“反馈与帮助”。二级页面新增返回，并高亮对应底部主栏目。
- 教员：31个模块按工作流分组、即时搜索；移动菜单使用可关闭抽屉，首次打开才加载组件，关闭后保留动画和焦点恢复。原接口权限过滤保持。
- 核销：输入/扫描→预览确认→完成，已完成与当前步骤用文字和图形共同表达。现有禁权、过期、重复核销处理不变。

## 动效与访问方式

| 场景 | 实现 | 减少动态效果 |
| --- | --- | --- |
| 切换底部主栏目 | 220ms选中背景位移 | 即时切换 |
| 点击按钮/图片入口 | 150ms轻微按压与颜色反馈 | 保留颜色，取消位移 |
| 展开钱包状态 | 180ms短距离展开反馈 | 立即显示 |
| H5选项面板 | 220ms面板进入、背景遮罩 | 无进入动画 |
| 网络请求中 | 顶部进度提示及原禁用状态 | 静止进度提示 |

微信沿用原生Picker。H5面板挂到页面顶层，避免粘性筛选栏形成的层叠上下文遮挡；锁定Taro真实滚动容器，保留Escape、Tab循环与焦点恢复。没有自动轮播、全屏视差、长时间入场或乐观“到账”动效。

技术参考：[Taro Button](https://docs.taro.zone/docs/components/forms/button/)、[MDN reduced motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion)。本地技能 `impeccable`、`web-animation-design` 用于设计判断；三维重建技能评估后不适用二维平台。页面捕获和访问性检查阶段使用 `stitched-full-page-capture` 与 `accessibility`。
