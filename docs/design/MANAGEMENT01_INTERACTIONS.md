# MANAGEMENT01 学生参与与管理交互决定

本切片依据0.7.0已提交合同。课程创建和发布是教员管理操作；学生仅获取公开题目，不能调用答案管理接口。新课程与宣传任务先报名/认领，再提交成果；报名与认领不记分。宣传要求私有源文件、原创授权、发布链接和本人角色贡献，随成果提交为服务端快照。

学生“项目→招募”展示公开招募和本人申请；运营录取后必须用全部录取成员组队，学生再到既有项目页面确认贡献分配。组队表固定已录取名单快照及招募版本，刷新发现其他页面录取了新人时要求重新载入比例。申请和录取不发分。

学生“我的→入社申请”按真实身份和历史申请呈现；已认证无需重复申请，待审核显示申请记录，已拒绝说明当前合同不支持重提。访客DEMO_S016来自A提交9372bd3a，其批准状态不被种子重置。membership01真实跨身份4项通过；首次访客→PENDING→独立审批→ACTIVE，钱包不变。小程序仅构建验证，不声称真机通过。

课程保存、发布、停用按钮使用稳定的可访问名称及忙碌状态。回归实际捕获到AntD退场加载图标残留在访问树中，使按钮名称变成“loading 发布课程”；使用显式aria-label保持读屏与操作一致，忙碌时禁用。创建与详情共用单个抽屉。完整结果在B交接中记录，本设计说明不作为未执行流程的通过证明。
