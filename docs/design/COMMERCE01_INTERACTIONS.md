# 预约、专项与质量退货交互

真实目录kind决定下单入口：普通实物走原订单，service读取时段，application读取专项方案。时段名额和时间、专项额度及凭证要求均从服务器读取，最终资格/名额/月限兑/版本由API判定。申请提交只传合同字段，不本地伪造订单。

专项使用“审核归档”，同时展示门槛、零消费与申请金额，避免把模拟审核当成现金发放。服务页面独立显示安全要求，现场本人及安全确认交工作人员，不能用积分作为许可。

退货只选择本人已领取整单，私有质量凭证必填；提交和双审不退款，实收隔离才显示服务器refundPoints/recoverySettledPoints。质检须不同收货自然人，重入可售与退出库存状态明确。心愿阅评不承诺采购、不影响余额。

业务写入按钮锁定防重；版本刷新不覆盖旧编辑内容。私有证据按具体商务事项授权读取、内存预览，每次下载重新请求，无公开文件URL。小程序仍保持可构建，平台私有图片预览限制保持明确。
