# 会议交互说明

学生会议与普通活动共享报名及签到。以服务端 Activity.ruleCode 识别会议，再用真实 Meeting.activity.id 关联 Meeting.id，禁止将两个编号互换。活动列表刷新同步会议与本人合并成果，避免子组件挂载与外层请求锁竞争导致首屏静默未加载。

每场会议一次合并申报，登记主持人禁选普通参与，其他成员禁选主持。表单只传合同 parts、description、evidenceFileIds，不传估算分。服务端独立校验起止签到、状态、贡献上限、月度参与上限及利益回避。

待审核与待比例解锁独立展示；结算页直接读取 postedPoints/pendingPoints。批准信息不宣称全部到账；同学期主动分比例、FIFO整笔处理及跨学期隔离均由服务端执行。原始来源编号保留便于核对。

后台单一会议详情连接活动页面，深路由按已授权列表定位，刷新可恢复。所有保存/审核按钮给出稳定 aria-label 与 aria-busy，加载时禁用以防重复提交。
