## 已走通的完整路径

| 流程 | 学生与教员之间的实际路径 | 验证到的结果 |
|---|---|---|
| 新成员 | 我的→入社申请→填写意愿→独立职员审批→学生刷新 | 资格变为ACTIVE，积分与成长不变 |
| 活动成果 | 发现/活动→报名→起止签到→提交成果→现场事实签认→要求补证→学生首页补材料→新轮签认→独立审批→木能量明细 | 原材料、原决定可追溯；新轮不沿用旧事实签认；通过后仅入账一次 |
| 学习与翼章 | 学习目录→认领→学习/作答→成果验收→技能翼章与账本 | 后端判卷；失败不发分；课程创建者回避；通过独立技术验收后发放翼章 |
| 团队项目 | 公开招募→学生申请→运营录取与组队→各成员确认分配→四阶段提交和双人验收 | 分配版本与成员名单冲突被阻止；阶段权益按确定性分配入账 |
| 赛事 | 项目与竞赛→填报→独立验收→验收记录→填写晋级或更正 | 同作品250升至1000只补750；更正沿用原作品与成员；撤销使用现有规则 |
| 兑换领取 | 奖励→兑换预占→订单详情→备货→本人领取凭证→教员扫码/手输→预览→显式确认→库存与账本对账 | 预览无副作用；重复核销不二次扣减；合法成长不因兑换减少 |
| 取消与恢复 | 兑换确认响应丢失→原幂等键重试/订单找回→正常取消 | 仅一笔订单、一份预占；取消归还原批次，保留历史 |
| 服务/专项 | 奖励→服务时段或专项方案→材料→两位独立审核→服务真实时间内安全核验与履约/专项归档 | 预约取消释放名额；服务只消费已预占积分；专项门槛不扣点、不支付现金；真实月度限次保持有效 |
| 采购与退货 | 采购申请→双审入库；领取→质量退货凭证→双审→实物收齐→隔离→另一人质检 | 收齐才退款；收货人不能自检；库存、采购成本、返还账本一致 |
| 申诉 | 通知与申诉→本人陈述→裁决→申诉→独立自然人复核→撤销通知 | 原裁决人回避；资格恢复；不擅自改写合法钱包与成长 |
| 私有材料 | 本人上传→业务关联→授权预览/下载→关闭、离页或401 | 无关学生与系统管理员404；下载字节一致；503原幂等键重试；离页立即清除预览 |
