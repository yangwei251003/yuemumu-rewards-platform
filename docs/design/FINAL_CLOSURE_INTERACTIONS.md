# 最终闭环界面说明

学生“我的”按真实事项进入积分核对、转化核查、通知与申诉；活动内显示补证入口。新入口沿用已有蓝白橙色、移动触控尺寸、文字与证据表单，不生成新的奖励制度。

转化记录显示“本次核验人数”“本次累计目标”“当前已结算累计”。最后一项是该目标当前权益累计，不把旧请求的数值误称为旧请求单笔到账。原稿20与转化20分开，后者归零不抹掉前者。服务器变更档位时保留旧申请，按合同拒绝旧申请后重提。

积分核对要求真实原始模拟业务依据及私有文件；冲正输入仅原流水编号，不编辑负余额。复核与補证保存各轮材料，新一轮版本改变不会让旧草稿静默提交。用户明确重新载入时清空文件正文与预览，避免不同轮次错挂。

权限管理显示申请前角色及范围、独立意见、生效时间和事件。技术管理与业务审核分开；范围使用精确组织或资源编号，授权审核资格不能新增。菜单仅作为入口提示，每次操作仍由API验证。

身份退出或401使当前代际失效。迟到的页面读取、私有预览及写后刷新均不能恢复旧身份。断网重试保持原操作幂等键；已创建订单仍通过原订单取消或履行，不能用本地成功提示替代服务器状态。

图片仍使用已提交原创模拟示意资产，不暗示实际采购或真实产品规格。小程序只确认最终可编译；H5的真实界面测试与微信设备能力分开记录。
