## 主路径
首次 G1 实测的 S001 通过历史模拟事件得到可用木能量860、成长里程1240，完成4小时装调实训后达到910，再兑换900分R019；这条原始闭环有独立主集成证据。当前库已经保留了后续操作，不能把历史初始数字当作现在余额，也不能为了演示重置账本。

本次复演先记录当前余额。运营创建并发布新的4小时实训，学生报名并完成起止签到、提交成果；运营确认结束，导师独立事实签认，审核员批准后可用与成长各增加50。用这笔实际新增积分兑换30分的R001（或选择当前余额可承担的实物），预占后可用减少、冻结增加，成长不变。创建者尝试自审应被拒绝，再由独立审核员处理。
职员在手机核销页预览该订单→确认→订单FULFILLED、冻结0、可售与实物库存口径一致，审计记录操作者与规则。再扫同一码，明确已领取且不重复扣减。

## 管理能力

当前有16个虚构学生/访客和9个虚构职员。新增访客用于入会，T008独立审核员与T009独立教员用于原审者回避后的复核。名册与规则仍为模拟资料，不代表真人授权。

- 身份：访客申请入会后独立批准；系统管理员提出角色或范围变更，两位有权限的独立复核员审批，原会话立即按新范围受限。
- 课程与宣传：管理端发布题目及验收要求，学生认领、服务端判题、提交私有源文件和授权说明。转化目标先登记，关联活动实际报名人数达到档位后双审，只补累计差额；原基础成果撤销时走同源下降更正。
- 会议：先建学期与场次，再按实际参与角色申请；纯参会月20、单次25和主动/被动比例在待结算明细解释。
- 项目P003团队池1600，10/25/25/40阶段，成员占比分配总和100%；展示四人各400上限与最大余数机制。
- 模拟比赛记录校级250→省级1000，只加750；如果其他系数/上限适用先展示计算明细。
- 组织者试图审核自己的申请被拒绝；第二个真实独立demo职员完成审核（模拟身份不代表生产双审已满足）。
- 一条失约提醒与一条申诉，独立复核后撤销限制；不会把所有合法积分清空。
- 普通抽查10%、高风险待复核、低库存、待补货、模拟预算报表。
- 商务：真实服务预约可取消、需到时间且安全条件核验后履约；专项申请只审核归档不扣点或支付现金。采购双审后入库并记录成本；已领取实物整单退货需收齐和隔离，退款不增加成长，收货人不得兼任独立质检。
- 纠错：补分必须带原始凭据并双审；补证创建新审核轮次，历史证据及决定保留；申诉中的实质新证据可续办，原审者回避。积分核对页显示源账本与投影，后台周期检查发现差异只追加告警，不覆盖原账。
- 数据：预算版本、费用冲正、匿名CSV、导入预览和确认、系统健康均读取真实本地API。重复导入不创建第二份身份，也不自动给积分。
