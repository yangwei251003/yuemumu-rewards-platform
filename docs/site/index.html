03 / RUN LOCALLY

从源码运行完整示例。

需要自己的Node.js、pnpm、MySQL和Chrome。具体版本、隔离配置与启动步骤见README；先创建新示例库，不接入原有数据库。

获取源码git clone https://github.com/yangwei251003/yuemumu-rewards-platform.git
安装与准备pnpm install --frozen-lockfile
pnpm run setup integration
pnpm db:start
pnpm db:migrate
pnpm db:seed
构建与启动pnpm build
pnpm demo
pnpm health
