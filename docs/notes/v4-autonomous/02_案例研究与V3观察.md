# 粤木木下一轮升级：案例研究与 V3 观察

调研日期：2026-09-06。用途：给当前项目中的单个新任务窗口提供研究起点和可核验依据，不预先决定新页面样式。

## 一、先区分证据

本次检查了用户新上传压缩包的文件目录、发布清单、HTML 指导书、PDF 的文字与渲染页，以及 student-home.png。外部研究参考奖项主办方项目页、设计团队复盘和可取得的界面展示材料；未逐一登录这些微信小程序。部分外网高清图片无法完整打开，不能由奖项描述推断其全部视觉细节、动效或当前线上状态。

获奖、用户规模、业务表现和设计质量是不同证据。获奖记录并不等于拥有很多用户；设计师介绍中的目标也不等于已经测得的改善。案例中的上线年份不能自动当成获奖年份，历史截图不代表 2026 年线上版本。下面“可迁移的判断”是针对粤木木的分析，不是原作者的结论。

## 二、上传 V3 的现状：能确认什么，不能确认什么

发布清单标记为 v3-teacher-demo-20260906，类型是 local-guide-and-shortcuts-not-standalone-installer。压缩包有指导书、首页截图、两枚 Logo 和本机启动脚本，没有完整应用源码。启动入口依赖用户原来的本地项目及运行配置。本次没有运行该实际业务系统，也没有实测教员后台、全部二级页面或微信真机。

清单引用了 evidence/v3/receipt.json，但这个证据文件未随压缩包提供。指导书自述的测试次数与截图数量，不是本次独立验证结果。

### A. 首页截图的直接观察

对应 references/student-home.png，390×1000 像素。

这张静态图不支持对页面动画、触控流畅度、加载速度、键盘遮挡或实际报名成功率作结论。实际实现时需要补齐验证。

### B. 教员端已做过什么

V3 指导书已明确写了“今日工作、教学活动、项目竞赛、审核中心、奖励服务、运营设置”六个工作域，并列出 31 个后台模块。因此，下一轮不应把“重新合并成六类”当作新成果。更值得检查的是：教员处理一条具体事务时，是否还需要跨模块找材料、记编号、重复筛选，是否清楚当前角色能做什么。

指南区分木能量、成长里程与技能翼章，描述独立审批、回避、领取预览与确认等业务边界。新设计可以改变呈现和组织方式，但应以真实仓库确认规则，不擅自将它们合并或取消。

### C. 一个交付细节

这份 PDF 实际有 9 个物理页面，其中第 6 个物理页面只有承接上一页的页脚文字，而文档中的编号仍按 8 页书写。这是文档排版问题，不是系统业务故障；可作为后续交付自查的提醒。

## 三、精选案例：事实与迁移判断分开

### 1. 佳士得 Live Auction 微信小程序

**证据：** 红点官方列为 2023 年 User Interface, UX/UI Design 项目。[R1] 设计团队案例说明其针对本地使用习惯调整交互，并在首页呈现与用户相关的拍卖及拍品。[R2] 本次可见的案例展示图以拍品/专题图片、留白和明确层级呈现内容；这不是实际登录后录制的完整流程。

**可迁移的判断：** 内容本身可以成为视觉主角，个性化应体现为相关内容与行动，而不仅是一句问候。粤木木可审视项目、训练和奖励图片是否真正有内容价值，不需要复制奢侈品风格或建立庞大推荐系统。

### 2. 云游长城 / The Great Wall E-tour

**证据：** 红点官方 2023 年项目页展示 Best of the Best 标记。[R3] 主办方采访确认它使用微信小程序框架与云渲染，以虚拟游览和维护活动参与长城保护。[R4]

**可迁移的判断：** 互动可以承载主题和知识，而非仅装饰页面。无人机成长可探索合适的参与式表达，但不能据此要求复制云端 3D 世界；复杂渲染是否值得，需要根据真实收益和运行成本判断。

### 3. 东芝家电小程序 / Toshiba Home Appliance Mini Program

**证据：** iF 获奖库收录，说明它将设备激活、控制、管理、售后、内容与服务整合到微信轻量入口；页面列出的上线年份为 2024，不在此推定获奖年份。[R5]

**可迁移的判断：** 丰富功能可以围绕用户正在处理的对象组织，而非逐项暴露内部模块。粤木木应研究同一活动、同一申请或同一订单中的操作能否连贯完成，而不是只缩短菜单。

### 4. StoryTeller 微信博物馆语音导览

**证据：** iF 官方项目页收录该微信小程序，介绍它借助 iBeacon 导览降低另外安装 App 的门槛，并简化功能和交互。[R6]

**可迁移的判断：** 关键不在堆功能，而在使用场景到达时立即能完成任务。对粤木木而言，可审视从通知、活动或领取凭证进入后是否直达对应上下文；不需要为此增加定位硬件。

### 5. 青松助手 / Qingsong Assistant

**证据：** 红点官方项目页介绍这是面向老年用户的微信小程序，通过更大的图文教程及更易识别的可点击内容降低手机使用门槛。[R7]

**可迁移的判断：** 初次使用的教员需要当前页面中的明确对象、可执行动作和结果说明，不应依赖记忆后台术语。借鉴的是可理解性，不是将学生端整体改成适老产品。

### 6. 云游敦煌——品牌设计案例，不在这里冒称获奖

**证据：** 腾讯 CDC 署名的 2020 年复盘将石窟、壁画与矿物颜料转化为卡片、底纹、图标和主题色，并介绍日更内容的组织方式。[R8] 腾讯在 2021-05-19 的官方文章中称，当时已有近 3988 万用户通过该小程序浏览数字化文物；这是历史口径，不是目前活跃用户数据，也不能证明视觉设计独自造成了这个规模。[R9]

**可迁移的判断：** 品牌感可以贯穿产品语言，而不是只出现在横幅上。粤木木需要提炼自己的实践、器材、团队与成长内容，而非直接套用“科技蓝＋雷达线”；不复制敦煌纹理和配色。

### 7. 西门子官方小程序——用户服务与员工工具的补充案例

**证据：** MUSE 官方条目标注 2023 年、App—Shopping，描述首页与服务结构调整，以及面向销售和工程人员的工作台。本次通过文本抓取取得官方描述，未核实具体奖级，也未实测界面。[R10]

**可迁移的判断：** 学生端与教员端应被视为同一服务过程的两面。学生看到的状态，要能对应教员实际执行的步骤；不能两端分别美化却留下交接断层。

## 四、如何使用这些研究，不把下一版再次限定成模板

这些案例不是拼贴素材库，也不是必须全部实现的功能清单。它们共同提出几个值得验证的问题：产品是否拥有自己的表达，主次是否清晰，内容是否可信，用户是否始终知道现在与下一步，复杂流程是否被组织为可理解的任务。

让 Astra 自行形成可视方向并比较，不固定颜色、菜单数、首页顺序或动效形式。对首屏、二级任务与后台效率都保留质疑权。漂亮截图只是一个维度；关键交互失败、用户不懂、低端机卡顿或业务规则变弱，都不能用视觉分数抵消。

评价时优先保留实际截图、操作路径、状态变化、测试条件和可复现问题。模型自查不等于用户研究，自动化耗时不等于人的完成时间，“更少点击”也不能来自取消必要确认。对尚未测量的用户喜爱、留存和效率，不编造数字。
