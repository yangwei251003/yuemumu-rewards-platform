# 自主解决问题与阻塞管理

## 原则
“自主”是调查证据、选择可撤销的合法替代、实现并验证，不是绕过安全或假装服务已经具备。模型强弱不改变费用、授权、事务和生产门。

| 问题 | 自主可选路径 | 不能冒称 |
|---|---|---|
| 没腾讯云 | 本地MySQL/目录存储/静态构建 | 已经云上线 |
| 没微信AppID | Taro H5、demo认证、weapp编译 | 微信登录真机已验 |
| 没学校SSO | 虚构名单；正式授权CSV导入适配 | 学校认证已接通 |
| 没图像API/额度 | 可用内置工具、原创SVG、授权素材 | 已生成实际品牌商品照片 |
| Docker不可用 | 当前MySQL服务/官方原生服务 | SQLite测试等价MySQL并发 |
| 两窗口资源不足 | 减少子代理、只跑一套集成、静态构建 | 所有测试都已执行 |
| Tunnel打不开 | 同机/合法局域网；实际流程录屏补充 | 公网可达、永久免费稳定 |
| GitHub无权限/CI配额 | 本地Git/本地完整测试、后接远程 | 已有分支保护/云CI |
| API限流/网络限制 | 缓存、退避、官方替代、关闭非核心功能 | 轮换账号/凭据规避额度 |
| 未定制度/预算 | 按已标注demo默认继续，记录差异 | 已获教员批准或资金支持 |

## 工具使用
先列当前可用工具、插件和技能，优先官方文档、现有连接、当前代码和实际错误日志。只在相关能力可用时调用，不硬写未知工具API。网络来源入research记录：日期、URL、许可、版本、采取/不采取理由。
用户允许调研与本地实现，不等于同意任意下载安装、提权、付款、公开、创建云资源或提交含个人数据的表单。遇此类需要权限的事项列“唯一必要人工动作”，其他工作继续。

## 阻塞报告
BLOCKER编号、影响模块、已尝试路径/结果、替代方案、费用/权限影响、可交付范围、剩余人工动作、是否阻止G0/G2/G4。只缺微信凭据不应阻止H5演示，但缺任何真实MySQL可用环境会阻止事务验证，不可装作通过。
