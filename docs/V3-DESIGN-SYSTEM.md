# V3 Design System

方向：校园飞行实践手册。深航蓝作为可靠底色，科技蓝用于操作，品牌黄只作航线、编号和强调。学生页面有实践场景，后台采用清晰工作清单。保留授权Logo比例和文字。

| Token | 值/用途 |
|---|---|
| navy / ink | #142D4E / #172B4D |
| action | #155EEF（白字主按钮） |
| brand-yellow | #F4CE46（深蓝文字，禁止黄底白字） |
| surface / background | #FFFFFF / #F3F6FA |
| secondary / border | #526477 / #DCE5F1 |
| success / danger | #146541 / #A22B36，均配文字 |
| radius | 大卡16、小卡12、按钮10、Drawer16、Tag999 CSS px |
| shadow | 0 4px 18px rgba(20,45,78,.05)，不叠套卡片 |
| space | 4/8/12/16/24/32/48 CSS px |
| motion | 160ms按压、220ms展开、280ms初次进入；减少动画全部关闭 |

字体使用本机 PingFang SC / Microsoft YaHei / sans-serif；无外部字体请求。数字使用 tabular-nums，避免变化时跳动。Display 36、H1 26、H2 20、H3 17、Body 15、Secondary 13、Caption 12、Number 40 CSS px；学生样式沿用 Taro 750设计单位（约2倍CSS px），不可直接照抄后台px。

首页顺序：身份 → 品牌场景/真实近期活动 → 三体系摘要 → 我的下一步 → 真实能力矩阵 → 最近记录。没有服务端等级阈值时只显示真实成长里程，不编造Lv和进度。收益周统计没有聚合接口，不用分页账本冒充完整本周变化。

首页优先显示最紧要的1条（其他事项从活动/订单/通知进入），避免摘要被推离首屏。下一步优先：待补材料 → 已备货订单 → 本人尚有效报名 → 未读通知 → 真实开放活动/项目。活动时间基于北京时间，过期PUBLISHED不当未来训练推荐。局部读取失败展示重试，不能显示无待办。入口尽量定位实际对象。

活动图与类型由真实名称/规则做展示分类，不能新增报名规则。图片为明确标记的AI场景示意，不是活动实拍；没有地点字段则待负责人确认。核心CTA定位报名/签到/成果区域，不自动执行写操作。

后台6工作域，保留31旧URL；首页不嵌奖励目录/宣传Banner。待办按类型、对象、阶段、状态展示，采用既有API权限与完整分页，未返回时间就显示“时间未提供”。详情保留版本、理由、预览和确认。全局检索先覆盖授权菜单和当前已加载待办；不新增全库敏感数据搜索。

素材：assets/v3按hero/training/fpv/engineering/learning/project/reward/badge/empty/brand归档；生成原图、prompt、裁切、压缩、哈希和使用点写manifest。只复用许可清楚的既有图。关键FPV检查四臂四电机四旋翼、单组桨叶、相机、电池、天线，保留检视记录。新图目标≤160KB，首屏≤120KB，其他lazy-load。翼章为系统内部技能记录。

交互：主要触控≥44 CSS px；表单每字段label；可见focus；状态不只靠颜色；抽屉焦点可返回；safe area与键盘保留；活动CTA不得遮住TabBar或提交表单。超长文本换行、表格只在自身容器横向滚动。所有功能在0动画时成立。
