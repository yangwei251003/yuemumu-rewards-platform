# V3 素材库

4 张官方内置 imagegen 场景，全部已打开验图、压缩、接入真实页面并经浏览器截图检查。不是本校实拍，不代表实际活动场地或官方资质。页面均标注 AI 场景示意。

源 PNG 留在对应目录；发布 JPEG 为 960×640、quality79。学生端打包副本在 apps/student/src/assets/v3。manifest.json 保存源及输出 SHA256、字节数和逐图检查结论。压缩无需新增项目依赖，复现工具 scripts/v3-assets.mjs 可使用环境已有 sharp。
